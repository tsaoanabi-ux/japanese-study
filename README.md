# 日语学习网页 · N5 → N2 核心版

这是一个个人自用、纯本地优先的日语学习网页。双击 `index.html` 即可使用核心学习功能，不需要 API Key、Python、服务器或付费 AI。

## 当前内容量

- 语法：341 项（N5 → N2 高频核心语法与重要辨析）
- 单词 / 固定表达：1303 项（N5 → N2 大规模高频核心库）
- 跟读材料：48 篇（每级 12 篇）
- JLPT 语法快练：40 道
- 动词变形训练词源：50 个

- JLPT 四选一快练

## 学习与复习流程

现在采用“学习”和“复习”分离的逻辑：

1. 在 **单词库 / 语法库** 先学习读音、含义、搭配、接续和例句。
2. 学完后点击 **「学过了 · 加入复习」**。
3. 到期后内容才会进入 **复习** 页面。
4. 单词复习：先看汉字/图片，自己输入平假名或片假名，再看答案与搭配。
5. 语法复习：先根据目标语法自己造句，再看本地规则反馈和参考例句。
6. 最后选择记忆程度，系统自动安排下次出现。

SRS 记忆档位：

- **完全忘了**：10 分钟后再次到期
- **有印象**：约 1 天后再次出现
- **记得意思**：约 3 天后再次出现
- **熟练掌握**：进入约 14 天起步的长期复习

前三档都不会从复习计划中消失；只会改变下一次出现时间。即使选择“熟练掌握”，也不会永久删除，而是拉长复习间隔。

## 使用方法

1. 解压 ZIP。
2. 双击 `index.html`。
3. 直接开始学习。

建议使用最新版 Chrome / Edge / Safari。系统朗读的自然度取决于设备中安装的日语语音。

## 内容原则

不追求“看起来很多”的生僻词库。优先收录：

- JLPT N5 → N2 高频内容
- 日本现实生活常用词与表达
- 阅读、工作、通知里高价值的 N3 / N2 抽象词
- 值得长期掌握的固定搭配

真实 JLPT 试题全文和影视剧台词不会直接复制；跟读阅读和影视感内容为原创训练材料。
