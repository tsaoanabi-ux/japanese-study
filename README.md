## 最新学习逻辑

### 学习与复习分开
单词库 / 语法库负责理解；真正的输出测试只发生在复习中心。

- 单词复习：自己输入平假名 / 片假名
- 语法复习：自己造句

### 艾宾浩斯复习骨架
基础节点：

**10 分钟 → 1 天 → 3 天 → 7 天 → 15 天 → 30 天 → 60 天 → 90 天**

系统会根据你的真实记忆程度动态前进或回退：

- 完全忘了：回到 10 分钟
- 有印象：回到 1 天
- 记得意思：继续推进
- 熟练掌握：跨级推进到更长间隔

所有档位以后都会再次出现；熟练掌握也不会永久删除。

### 3 分钟微复习
每次只抽 5 项，优先到期、薄弱和最近学过的内容。

如果正式复习还没到期：
- 微复习答对，不会把正式复习往后推
- 微复习答错，会提前拉回复习

首页记录最近 7 天微复习习惯和连续天数。

### 今日学习负荷控制
系统根据到期复习数量给出当天建议。默认顺序：

**复习 → 少量新学 → 5 分钟跟读收尾**

欠账很多时会建议暂停新增，避免“只顾学新内容、旧内容全忘”。

### 我的记忆钩子
每个单词和语法都能保存自己的简短笔记、联想、易错点或私人例句；复习时会重新显示。

## 使用原则

1. 先回忆，再看答案。
2. 不要因为“看着眼熟”就选熟练。
3. 一天到期很多时，宁可减少新学。
4. 微复习每天 3 分钟，比偶尔一次长时间突击更容易坚持。
5. 单词优先记搭配，不只记中文翻译。
6. 语法通过造句完成主动输出。

## 数据

学习记录、SRS 节点、微复习习惯、错题、个人记忆钩子等都保存在浏览器本地，并支持 JSON 导出 / 导入备份。
