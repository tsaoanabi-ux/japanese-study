- 单词 / 固定表达：1303 项

## 当前学习逻辑

### 1. 单词库 / 语法库负责学习

学完一个内容后点击「学过了 · 加入复习」。

列表会直接显示学习状态，不需要反复点进去确认：

- `✓ 已学 · 待复习`：已经到期
- `✓ 已学 · 10分钟 / 1天 / 3天…`：当前所处记忆阶段
- 没有标记：还没有正式加入学习计划

### 2. 只有一套「今日复习」

不再把“标准复习”和“微复习”拆成两套相似入口。

今日复习会自动组一轮题：

1. 真正到期的内容优先。
2. 如果到期内容不足 5 项，会自动补少量薄弱项、近期学习项或快要到期的内容。
3. 额外巩固卡答对不会把原来的正式复习时间往后推；答错则会提前拉回复习。

这样即使今天只有 1 个到期内容，也不会通常只做 1 题就结束。

### 3. 忘记的卡「本轮就会再见」

复习中如果选择：

- **完全忘了**：正式节点回到 10 分钟，同时这张卡会在当前这一轮过几题后重新出现。
- **有印象**：正式节点回到 1 天，同时本轮稍后再回看。
- **记得意思**：继续推进艾宾浩斯阶段。
- **熟练掌握**：跨阶段推进，但以后仍然会再次出现。

也就是说，10 分钟 / 1 天是**下一次正式复习节点**，不是让你现在做完一题后停下来等计时器。

同一张薄弱卡在一轮里最多安排少量回看，避免无限循环；正式的 10 分钟复习节点仍然会保留。

### 4. 艾宾浩斯复习骨架

基础节点：

**10 分钟 → 1 天 → 3 天 → 7 天 → 15 天 → 30 天 → 60 天 → 90 天**

系统以这条曲线为骨架，再按照你的真实表现前进或回退。

### 5. 每日提取习惯

不再需要单独打开“微复习”。

每天在今日复习中完成至少 **5 次主动回忆**，首页就会记录为当天习惯完成。

核心目标是：

**少量、高频、每天出现。**

### 6. 专项复习

复习中心还包括：

- **JLPT 语法快练**：练接续、语义和相似语法辨析；答错会把对应语法拉回主复习。
- **动词变形专项**：练 ます、て、た、ない、可能、意向、ば、命令、被动、使役、使役被动；错误会进入优先回抽。

### 7. 首页

首页是学习驾驶舱，不替你强制布置任务。

你可以自己设定：

- 今日新学语法目标
- 今日新学单词目标

同时首页展示：

- 现在到期数量
- 下一次复习时间
- 薄弱项
- 近 7 日正确率
- 未来 24 小时 / 3 天 / 7 天复习压力
- 每日提取习惯
- N5 → N2 长期掌握度

### 8. 我的记忆钩子

每个单词和语法都可以记录自己的简短联想、易错点、私人例句或区别提示，复习时会重新显示。

## 建议使用顺序

**今日复习 → 按自己目标少量新学 → JLPT/动词专项 → 5 分钟跟读**

复习积压很多时，优先处理旧内容，不要继续大量开新卡。
