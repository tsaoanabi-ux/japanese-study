# 日语学习网页 · N5 → N2 高效学习版

这是一个个人自用、纯本地优先的日语学习网页。核心功能无需 API Key、Python、服务器或付费 AI。

## 当前内容

- 语法：341 项（N5 → N2 高频核心语法与辨析）
- 单词 / 固定表达：1303 项
- 跟读材料：48 篇
- JLPT 语法快练：40 道
- 动词变形训练词源：50 个

## 这版最重要的学习逻辑

### 1. 学习与复习彻底分开

单词库 / 语法库只负责“理解”。

- 单词：读音、意思、图片、搭配、例句、用法
- 语法：意思、接续、例句、辨析、JLPT 提醒

学完后点击「学过了 · 加入复习」。

真正的输出测试只发生在复习中心：

- 单词：自己输入平假名 / 片假名
- 语法：自己造句

### 2. 艾宾浩斯复习骨架 + 动态调整

基础记忆节点：

**10 分钟 → 1 天 → 3 天 → 7 天 → 15 天 → 30 天 → 60 天 → 90 天**

系统不是死套时间表，而是根据你的自评动态前进或回退：

- 完全忘了：回到 10 分钟
- 有印象：回到 1 天
- 记得意思：继续推进
- 熟练掌握：跨级推进到更长间隔

前三档一定还会出现；熟练掌握也不会永久删除，只会延长间隔。

### 3. 3 分钟微复习

新增「微复习」模式，每次只抽 5 项：

- 已到期内容优先
- 薄弱项优先
- 最近学过的内容适当加入

如果某项正式复习还没到期：

- 微复习答对，不会把正式复习往后推
- 微复习答错，会把它提前拉回复习

这样可以避免“因为刚看过所以误以为会了”的假熟悉感。

首页会记录最近 7 天微复习习惯和连续天数。

### 4. 今日学习负荷控制

首页不再给固定学习清单，而是提供状态判断：复习积压、下一次复习、未来几天压力和薄弱项。每天的新学语法与单词目标由用户自己设置。

### 5. 我的记忆钩子

每个单词和语法现在都可以写自己的简短笔记：

- 自己的联想
- 易错点
- 私人例句
- 和另一个词 / 语法的区别

复习时会重新显示自己的记忆钩子。

建议只写 1～2 行，不要抄长笔记。

## 复习原则

1. 先回忆，再看答案。
2. 不要因为“看着眼熟”就选熟练。
3. 一天复习很多时，宁可减少新学量。
4. 微复习每天 3 分钟比周末一次刷 2 小时更容易坚持。
5. 单词优先记搭配，不只记中文翻译。
6. 语法一定要通过造句完成主动输出。

## 复习中心：专项复习

复习中心现在包含四类训练：

- **标准复习**：单词假名 + 语法造句，按艾宾浩斯节点安排到期时间。
- **3 分钟微复习**：每天 5 项，优先薄弱、到期、最近学过的内容。
- **JLPT 语法快练**：四选一训练接续、语义与相似语法辨析。答错后，对应语法会被拉回 10 分钟复习节点。
- **动词变形专项**：ます形、て形、た形、ない形、可能、意向、ば形、命令、被动、使役、使役被动。答错或直接看答案后，会进入 10 分钟后的优先回抽队列。

语法库现在只负责理解语法本身；输出型训练统一放在复习中心，避免“刚学完就被测试”打断学习过程。

## 首页驾驶舱

首页不再自动生成“今日学习清单”。每天的新学目标由用户自己决定：

- 今日新学语法目标：可自由设置，0 表示当天不设目标
- 今日新学单词目标：可自由设置，0 表示当天不设目标
- 可以只保存今天，也可以保存为以后每天的默认目标
- 新学进度以点击「学过了 · 加入复习」为准，重复练习不会伪装成新学

首页重点展示真正有决策价值的信息：

- 当前已到期复习数量
- 下一次复习还有多久
- 最近薄弱项数量与重点错题
- 近 7 日真实正确率
- 未来 24 小时 / 3 天 / 7 天复习压力预报
- 3 分钟微复习习惯
- N5 → N2 长期掌握度

系统只给“现在最值得做什么”的提示，不替用户强制规定今天必须学几项。
